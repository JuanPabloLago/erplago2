# ERP Lago

Sistema ERP para gestión empresarial con integración AFIP.

## Características
- Gestión de productos, clientes, proveedores
- Facturación electrónica (AFIP)
- Control de inventario
- Caja y cobros
- Reportes

## Stack
- Node.js + Express
- PostgreSQL
- HTML/CSS/JS

## Instalación
```bash
npm install
npm start
```

**Nota:** Certificados AFIP no incluidos.
