Configuraciones de Inventario

Permitir Stock Negativo

Si está activado, el sistema permitirá ventas aunque no haya stock suficiente. El inventario puede quedar en números negativos. Útil para sistemas de pre-pedidos o cuando el stock físico se actualiza con retraso.

Información importante:
  • Los cambios se aplican inmediatamente en todas las operaciones de venta
  • Si está desactivado: El sistema bloqueará ventas sin stock disponible
  • Si está activado: Podrás vender incluso sin stock físico
Ocultar productos sin stock en la Web

Si está activado, los productos sin stock no aparecerán en el catálogo público de lago.ar. Los cambios se aplican la próxima vez que se sincronice el catálogo.

Permitir Modificar Precios en Venta

Si está activado, los vendedores podrán cambiar el precio unitario de los productos durante la venta rápida. Útil para descuentos especiales o precios negociados.

Atención:
  • Si está desactivado: Los precios se toman de la lista asignada y no se pueden cambiar
  • Si está activado: El vendedor puede editar el precio directamente en la tabla de venta
  • Los cambios de precio quedan registrados en el pedido

Configurá porcentajes de recargo (+) o descuento (-) para cada forma de pago. Los recargos generan Nota de Débito automática. Los descuentos se aplican directamente en la factura.

Seguridad — Dispositivos

Límite de dispositivos activos por usuario, según su rol. Cuando un usuario ya alcanzó su tope, el sistema no deja autorizar un dispositivo nuevo hasta dar de baja uno existente. Esto evita que una misma credencial quede habilitada en muchas máquinas.

Dejá el valor en 0 (o vacío) para un rol que no tenga límite. El límite cuenta solo dispositivos activos: los dados de baja no suman.
